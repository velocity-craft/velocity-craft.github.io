Draftly for Mac — Help and Support

Native Mac app · macOS 14 or later · Updated October 31, 2026

Use Draftly to write Markdown notes, organize them with folders and tags, and keep reference files close to your writing. You can start without an account.

Writing and organizing

Create a note with the new-note control or Command-N. Use the formatting controls while writing, and organize notes with folders, tags, pins, and favorites. Templates and snippets help reuse text. Search helps find notes in your library. Open a note in a separate window when you want to keep more than one piece of writing in view.

Importing files

You can import supported Markdown, text, image, and PDF files. Drag a supported file into the library or use the available import controls. Draftly creates an app-managed copy. Keep the original until you have checked the imported note; changes in Draftly do not update the original file.

Backup and restore

Open Settings → Backup & Restore and review the backup format and contents before saving. Keep your existing library and a separate backup until you have checked a restore. A restore that replaces data can change the current library.

Vault's authentication lock is separate from backup encryption. A Vault backup passphrase encrypts the Vault portion of a full backup, not the ordinary library portion. Without that passphrase, a full backup can include unencrypted Vault records. Store exported files securely and keep the passphrase somewhere you can recover it.

Dropbox and feature availability

Dropbox synchronization is currently limited to eligible test accounts. It is not generally available to every Mac user. Ordinary library synchronization is not end-to-end encrypted by Draftly, and the current synchronization path excludes Vault content. See the Mac Privacy Policy for details.

Optional system features depend on the app version, device support, and permissions. Manage available permissions in System Settings → Privacy & Security. Mac photo import uses a photo or file picker; direct camera capture is not available.

Purchases and installation

If a purchase is offered in your version, check the product, price, and terms in Apple's purchase sheet before confirming. For an existing Apple purchase, use the same Apple Account and the restore option offered by the app. A store connection problem is not a reason to purchase the same item again.

If App Store or TestFlight installation fails, note the exact message and time, macOS version, and app version or build. Do not remove a working installation or its notes before making a backup. Installation availability and beta invitations are managed through Apple.

Contact us

Email velocitycraft.app+draftly@gmail.com with what you were doing, the expected result, the actual result, and the app and macOS versions. A screenshot with private content removed can help. Please do not send passwords, encryption keys, or personal notes.

The in-app feedback flow lets you review technical details before sending. We use support correspondence to investigate and respond to your request.
