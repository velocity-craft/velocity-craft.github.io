Draftly プライバシーポリシー

施行日：2026年11月8日

本ポリシーは、Velocity Craft（以下「当社」）が配信する Android 版 Draftly に適用されます。

まず、当社にできないこと

何を保護しているかをご説明する前に、当社が主張しないことを先に記します。

  • この端末のメモは当社が独自に暗号化して保存しているわけではありません。ボールトも同様です。メモとボールトはアプリ専用の保存領域に保存され、Android OS が他のアプリから隔離しています。root 化された端末や、他人がロックを解除できる端末では、この隔離が破られる可能性があります。アプリロックとボールトのロック（生体認証または PIN）は2つ目の障壁ですが、アプリをロックするものであり、ファイルを暗号化するものではありません。
  • 当社はメモを復元できません。当社はコピーを保持していません。バックアップがないまま端末を失うと、メモも失われます。
  • 当社はセキュリティについて断定的な表現を使いません。そのような表現には確かめられる中身がないため、代わりに条件を記します。

メモの内容が当社に送られることはありません

Draftly はアカウント不要で、Velocity Craft はメモを保存するサーバーを運営していません。メモの本文・タイトル・フォルダ・タグ・画像・PDF・文書・リマインダー・ボールトの内容は、ご自身で移すことを選ばない限り端末に残り（下記「暗号化が適用される場所」を参照）、以下で説明する広告・分析・クラッシュレポートのサービスには一切渡されません。

スキャンした PDF ページの文字検索には、端末内で動作する文字認識（Google ML Kit）を使います。そのために PDF をアップロードすることはありません。

ユーザー向けのログインはありません。アプリには社内テスト用の Google ログインを備えた非表示の開発者パネルがあります。そこでログインしても、当社や Google の分析には何も送信されません。当社が指定したテスト用アカウントでログインした場合に限り、そのメールアドレスの一方向ハッシュがその端末の分析データとクラッシュレポートに付加されます。

これはメモとは別の話であり、当社は2つの説明を意図的に分けて記載しています。以下のいずれにもメモの内容は含まれません。Draftly は Google AdMob で広告を表示し、Google Firebase を利用状況の分析（Firebase Analytics）、クラッシュレポート（Firebase Crashlytics）、通知（Firebase Cloud Messaging）、リモートでの機能設定（Firebase Remote Config）に使用しています。これらが収集する情報は次のとおりです。

分析イベントには、レポートを分類できるよう、アプリのバージョン、ビルドの種類、ご利用プラン（無料または Lifetime）、端末の性能クラス（低・中・高）も含まれます。

Google アナリティクスは、端末モデル、Android のバージョン、言語設定、初回起動や利用時間などのセッション・エンゲージメント情報を、ランダムなアプリインスタンス ID とともに自動的に記録します。Firebase はクラッシュレポートを90日間保存し、分析イベントのデータは最長14か月間保存されます。

次の情報は収集しておらず、当社を通じて端末の外に出ることはありません：メッセージやメモの本文、写真や動画、ファイルや文書（PDF を含む）、音声、連絡先、カレンダー、健康とフィットネスのデータ、個人情報、正確な位置情報。Google は広告配信と分析レポートのために IP アドレスから市区町村レベルのおおよその地域を推定することがあり、Google Play のデータセーフティ欄ではこれを「おおよその位置情報」として申告しています。

Draftly は位置情報の権限を求めません。テンプレートには任意の {{LOCATION}} プレースホルダーを入れられますが、Android の設定でご自身が Draftly に位置情報へのアクセスを許可した場合に限り、Draftly は端末の最後の位置を読み取り、Android のジオコーディングサービス（ほとんどの端末では Google のもの）を使って都道府県・市区町村名に変換し、メモに書き込みます。その権限がなければプレースホルダーは空のままです。追加した写真にすでに位置情報が含まれている場合、Draftly はその座標をこの端末の画像メモとともに保存します。その座標はご自身のバックアップ（下記）の中にのみ含まれ、当社や広告・分析サービスに送られることはありません。

Draftly Lifetime を購入された場合、またはリワード広告で得た Plus Pass が有効な間は、広告は表示されません。ただし、同意設定と広告非表示の状態を確認するため、広告 SDK が端末上で起動することがあります。分析とクラッシュレポートはすべてのプランで同じように動作します。

暗号化が適用される場所と、されない場所

暗号化に関する記述は、特定の条件のもとでのみ正しいものです。メモが保存・送信されうる場所をすべて記します。

経路暗号化
この端末のメモのデータベース（ボールトを含む）いいえ。Android のアプリサンドボックスで保護され、アプリロックとボールトのロックを使えばさらにもう1層加わります。
「デバイスバックアップ」のファイル（バックアップと復元）いいえ。これらのファイルはこの端末の Draftly 専用フォルダに保存され、ボールトのメモを含むメモの本文が入っています。
Dropbox バックアップと「フルバックアップエクスポート」のファイル（ZIP）ボールトの部分のみ、しかもボールトバックアップのパスフレーズを設定した場合のみ暗号化されます（バックアップと復元 → ボールトバックアップの暗号化）。この場合、ボールトのメモはこの端末上で、パスフレーズから生成した鍵を使って AES-256-GCM で暗号化されます。それ以外のメモ・画像・PDF・文書は平文のファイルで、そのファイルや該当する Dropbox アカウントにアクセスできる人は誰でも読めます。パスフレーズを設定しない場合は、ボールトも平文のファイルとして含まれます。
他のアプリへの共有いいえ。メモのテキストやファイルは、選んだアプリにそのまま渡され、そのアプリのポリシーに従います。
Markdown・テキスト・PDF へのエクスポートと印刷いいえ。エクスポートは設計上平文です。他の場所で開くためのファイルだからです。
Android OS の端末バックアップ（自動バックアップ・端末間の移行）Draftly による暗号化はありません。Android のバックアップがオンの場合、メモのデータベース（ボールトを含む）、画像、PDF、文書、「デバイスバックアップ」のファイルは Google アカウントへのバックアップに含まれ、そのバックアップは Google が管理します。Draftly はログイントークン、アプリロックの設定、購入状態のキャッシュ、通知履歴、文書の編集履歴を除外しています。

ボールトバックアップのパスフレーズを忘れると、そのパスフレーズで保護されたボールトのメモを当社が復元することはできません。スマートフォンを失っても手元に残る場所に保管してください。

Dropbox バックアップ

Dropbox バックアップは任意の機能で、Plus ツールのひとつです（Plus Pass または Draftly Lifetime で利用できます）。Dropbox を連携すると、認証は Dropbox 上で行われ、連携トークンは Android Keystore で保護された暗号化ストレージに、この端末上でのみ保管されます。Draftly は Dropbox と直接通信し、Velocity Craft がメモを受け取るサーバーを運営することはありません。

1回のバックアップは ZIP ファイルと、アプリのバージョン・データベースのバージョン・バックアップ日時・メモ数・画像数・ファイルサイズを記した暗号化されていない小さな概要ファイルで構成されます。Draftly は最新の2つのバックアップを残し、それより古いものを削除します。Dropbox はこれらのファイルをお客様のアカウントに保存し、ファイルのパス、サイズ、アップロード日時、ネットワークアドレスなどのサービス上のメタデータを把握できます。Dropbox による取り扱いは Dropbox のプライバシーポリシーに従います。

Draftly をアンインストールしたり Dropbox との連携を解除したりしても、すでに Dropbox にあるファイルは削除されません。削除するには、Dropbox 内の Draftly のフォルダを削除し、必要に応じて Dropbox のアカウント設定でアプリの連携を解除してください。

他のサービスに接続する機能

  • 音声入力（音声入力と音声メモ）は、端末の音声認識サービス（ほとんどの端末では Google のもの）を使います。お話しになっている間、音声はそのサービスによって処理され、そのサービス自身のサーバーで、そのサービスのプライバシーポリシーのもとで処理されることがあります。Draftly は音声を録音・保存せず、認識されたテキストだけを受け取ります。読み上げには端末の音声合成（TTS）エンジンを使います。
  • リンクのプレビュー。メモにウェブリンクを貼り付けたり共有したりすると、Draftly はタイトルを表示するためにそのページを取得します。X/Twitter の投稿リンクでは、投稿の本文を表示するため、まず X の公開埋め込みサービス（publish.twitter.com）に問い合わせ、失敗した場合は独立したプレビューサービス fxtwitter.com に問い合わせます。ブラウザでリンクを開いた場合と同様に、そのサイトやサービスはリンクとネットワークアドレスを受け取ります。メモのそれ以外の内容は送信されません。
  • フォント。設定でフォントを閲覧・選択すると、Draftly は端末の Google Play 開発者サービスに、Google Fonts からのダウンロードを依頼します。
  • 文字認識は Google ML Kit により端末上で実行されます。Google の ML Kit 利用規約に記載のとおり、このライブラリは技術的な利用状況・性能の指標を Google に送信することがありますが、PDF やその文字は送信しません。
  • アプリの更新と言語パックは Google Play（アプリ内アップデート、Play Feature Delivery）を通じて配信されます。

第三者

  • Google AdMob と Google User Messaging Platform — 広告と同意の管理。Google のプライバシーポリシーが適用されます。
  • Google Firebase — Analytics の利用イベント、Crashlytics のクラッシュレポート、通知用の Cloud Messaging、機能設定用の Remote Config。メモの内容が Firebase に渡されることはありません。Google のプライバシーポリシーが適用されます。
  • Google Play — Lifetime 購入の決済（当社がお支払い情報を見ることはありません）、アプリ内アップデート、言語パック。
  • Google ML Kit と Google Fonts — 端末内の文字認識と、選択したフォント。
  • Dropbox — バックアップのためにアカウントを連携した場合のみ。
  • 端末の音声認識・音声合成・ジオコーディングのサービス — 使用している間のみ。
  • 貼り付けたリンク先のウェブサイト、X の埋め込みサービス、fxtwitter.com — リンクを貼り付け・共有したときに、タイトルや投稿の本文を取得するためだけに。

権限

  • 通知 — ご自身で設定したリマインダーと、アプリに関するお知らせ。リマインダーの通知にはリマインダーの文言とメモの一行が表示されるため、Android の通知設定によってはロック画面に表示されることがあります。プロモーション通知（当社の他のアプリのニュースや特典のご案内）は、設定 → 通知 でいつでもオフにできます。欧州経済領域、英国、韓国ではご自身でオンにするまでオフで、それ以外の地域ではデフォルトでオンです。
  • アラームとリマインダー、起動時の実行 — リマインダーを時間どおりに通知し、端末の再起動後にリマインダーを再設定するためです。
  • マイク — 音声入力や音声メモを使っている間のみ。
  • 位置情報（おおよそ・正確） — アプリに宣言されていますが、リクエストはしません。{{LOCATION}} テンプレートのプレースホルダーにのみ使われ、Android の設定でご自身が許可した場合にのみ機能します（上記参照）。
  • インターネットとネットワークの状態 — 広告、分析、リンクのプレビュー、Dropbox バックアップ、音声認識のため。
  • バックグラウンド処理（データ同期用のフォアグラウンドサービス、スリープ解除） — アプリがバックグラウンドにあっても、バックアップと復元を最後まで完了させるためです。
  • 生体認証 — アプリロックとボールトのため。指紋や顔のデータは Android の中にとどまり、Draftly が知るのは認証に成功したかどうかだけです。
  • 写真とカメラ — Android の選択画面とカメラアプリを使うため、Draftly が受け取るのは選んだ項目だけです。メディアライブラリ全体へのアクセス権限は求めません。
  • アプリアイコンのバッジ（Samsung） — Samsung の端末でアプリアイコンのバッジを表示・消去するためです。

欧州経済領域および英国

必要な場合、Draftly は広告の前に Google 認定の同意フォームを表示します。選択は設定からいつでも変更できます。選択に応じて、広告はパーソナライズされない形で表示されるか、まったく読み込まれません。このフォームが対象とするのは広告のみです。Firebase Analytics と Crashlytics はこのフォームの対象外で、すべての端末で動作します。Analytics は広告 ID を読み取ることがあり、広告 ID は Android の設定でリセットまたは削除できます。

お客様には、ご自身のデータへのアクセス、訂正、削除を求める権利があります。メモは端末とご自身が管理するストレージにのみ保存されているため、これらの権利はご自身で直接行使していただけます。アプリ内でメモを削除する、アンインストールしてこの端末のデータをすべて消去する、バックアップを使っていた場合は Dropbox の Draftly フォルダを削除する、Android の端末バックアップを Google の設定で管理する、といった方法です。分析・クラッシュ・広告のデータは Google が保持しており、お名前やメールアドレスとは紐付いていません（上記の当社指定のテスト用アカウントを除く）。これらのデータについては、Google のツールをご利用いただくか、当社にお問い合わせいただければ可能な範囲でお手伝いします。Draftly のデータを削除する方法もご覧ください。

お子様

Draftly は13歳未満のお子様を対象としておらず、お子様の情報を故意に収集することはありません。
