Inscape Mac 개인정보처리방침

Inscape Mac 앱에 적용 · 2026년 10월 26일 갱신

Inscape는 VelocityCraft가 개발한 개인 일기 앱입니다. 이 방침은 Mac 앱을 설명합니다. 다른 플랫폼의 Inscape는 데이터를 처리하는 방식이 다를 수 있습니다.

Mac에 저장하는 일기

Inscape 계정이나 인터넷 연결 없이 일기를 쓰고 읽을 수 있습니다. 일기, 검색 색인, 첨부 파일은 암호화된 로컬 보관함에 저장합니다. 로컬 암호화 키는 이 Mac의 키체인에 보관합니다. 테마와 목록 모양 같은 화면 설정은 로컬 앱 설정으로 저장합니다.

Inscape는 macOS에 Touch ID 또는 Mac 로그인 암호를 이용한 인증을 요청합니다. 앱은 인증 결과만 받으며 지문이나 Mac 로그인 암호를 받지 않습니다. Mac이 잠자기 상태로 전환되거나 사용자 세션이 비활성화될 때, 또는 Inscape가 백그라운드에 있는 상태가 5분 지속되면 앱이 잠깁니다.

암호화와 앱 잠금은 Mac 자체의 보안을 대체하지 않으며, 잠금 해제된 세션에 접근 권한이 있는 모든 프로그램으로부터 보호를 보장하지 않습니다. 이전에 내보낸 파일이나 운영체제의 백업은 앱의 암호화 관리 범위 밖입니다.

선택형 Dropbox 동기화

동기화는 선택 사항입니다. Dropbox를 연결하면 Dropbox에서 계정 연결 승인을 진행합니다. Inscape는 연결된 계정을 표시하고 연결을 유지하기 위해 Dropbox 계정 식별자, 표시 이름, 접근 및 갱신 토큰을 이 Mac의 키체인에 저장합니다.

앱은 Dropbox와 직접 통신하며 Inscape 전용 Dropbox 앱 폴더를 사용합니다. 일기와 첨부 파일 내용은 Mac에서 암호화한 뒤 업로드하며, 연결된 Mac에서 동기화 비밀번호로 복호화합니다. 동기화 비밀번호는 VelocityCraft나 Dropbox로 보내지 않습니다. VelocityCraft는 일기나 암호화 키를 수신하는 서버를 운영하지 않습니다.

Dropbox는 사용자 계정에 암호화된 동기화 파일을 보관하며 파일 경로, 크기, 리비전, 요청 시각, 네트워크 주소 같은 서비스 정보를 확인할 수 있습니다. 파일 이름에는 해시가 포함됩니다. 이 정보는 일기 내용의 암호화 범위에 포함되지 않습니다. Dropbox의 계정 및 서비스 데이터 처리는 Dropbox 개인정보처리방침에 따릅니다.

자동 동기화를 켜면 Inscape가 열려 있고 활성화되어 있으며 Dropbox에 연결되고 잠금이 해제된 동안 동기화할 수 있습니다. 현재 버전은 호환되는 Mac 보관함끼리만 동기화합니다.

백업과 내보내기

새 백업은 기본적으로 암호화합니다. 백업에는 동기화와 별도의 암호를 사용하며, 원하면 이 Mac의 키체인에 보관할 수 있습니다. 암호화 백업의 일기와 첨부 파일 내용은 보호하지만 백업 구조, 파일 크기, 생성 시각, 암호화 정보는 보일 수 있습니다.

사용자가 직접 백업 암호화를 끄거나 Markdown 파일, 첨부 파일의 복호화 사본을 내보낼 수 있습니다. 이 파일에 접근하는 사람은 내용을 읽을 수 있습니다. 저장 위치는 macOS 파일 대화상자에서 직접 선택합니다. 다른 서비스가 동기화하는 폴더에 저장하면 해당 서비스의 처리 방침이 적용됩니다.

잊어버린 동기화 비밀번호나 백업 암호를 재설정하거나 잃어버린 암호화 키를 복구해 드릴 수 없습니다. 복원 가능한 백업과 암호 사본을 안전하게 보관해 주세요.

분석, 광고, 접근 권한

Mac 앱에는 광고 SDK, 분석 SDK, 자동 오류 보고 업로드 서비스가 포함되어 있지 않습니다. 일기를 광고에 사용하지 않습니다. Apple은 자체 정책에 따라 App Store 정보, 시스템 정보, 선택적으로 공유한 진단 정보를 별도로 처리할 수 있습니다.

앱은 사용자가 가져오기나 복원을 위해 선택한 파일을 읽고, 백업이나 내보내기에서 선택한 위치에 파일을 저장합니다. 현재 버전은 기존 사진, 오디오, 동영상, PDF 파일을 가져오며 마이크로 녹음하거나 위치, 연락처, 캘린더를 수집하지 않습니다.

사용자 선택과 삭제

앱에서 일기를 편집하거나 휴지통으로 옮기고, 복원하거나 영구 삭제할 수 있습니다. Dropbox 연결을 해제하면 이 Mac에 저장된 Dropbox 인증 정보와 동기화 비밀번호를 제거합니다. 로컬 보관함과 이미 Dropbox에 저장된 파일은 삭제하지 않으며 Dropbox 계정 설정의 앱 연결 승인도 자동으로 철회하지 않습니다.

Dropbox 접근을 중단하려면 Inscape에서 연결을 해제하고, 필요하면 Dropbox 계정 설정에서 앱 연결 승인을 철회해 주세요. 클라우드 파일을 제거하려면 Dropbox에서 Inscape 앱 폴더를 관리해 주세요. 동기화는 이전 암호화 파일과 삭제 기록을 보존할 수 있으므로 일기 삭제가 모든 이전 클라우드 파일이나 백업 사본의 즉시 삭제를 뜻하지는 않습니다. 백업과 내보낸 파일은 저장한 위치에서 별도로 관리해야 합니다.
