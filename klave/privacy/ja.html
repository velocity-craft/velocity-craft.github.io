Klave プライバシーポリシー

施行日：2026年11月8日

本ポリシーは、Velocity Craft（以下「当社」）が配信する Android 版 Klave に適用されます。

まず、当社にできないこと

Klave は、お手持ちのファイルをそのまま扱うマークダウンエディタです。何を保護しているかをご説明する前に、当社が主張しないことを先に記します。

  • Klave はメモを暗号化しません。 メモは、ご自身で選んだフォルダやご自身の Dropbox にある普通のファイルであり、Klave はその場で編集します。そのフォルダや Dropbox アカウントにアクセスできる他のアプリや人も読むことができ、誰がアクセスできるかを決めるのは Klave ではなく Android と Dropbox です。
  • 当社はメモを復元できません。 当社はコピーを保持していません。フォルダや Dropbox のファイルが失われると、Klave でも元に戻せません。
  • 当社はセキュリティについて断定的な表現を使いません。そのような表現には確かめられる中身がないため、代わりに条件を記します。

メモの内容が当社に送られることはありません

Klave はアカウント不要で、Velocity Craft はメモを保存するサーバーを運営していません。メモの本文、ファイル名・フォルダ名、画像、PDF、文書は、ご自身で選んだフォルダまたはご自身の Dropbox に残り、以下で説明する広告・分析・クラッシュレポートのサービスには一切渡されません。

スキャンした PDF ページの文字検索には、端末内で動作する文字認識（Google ML Kit）を使います。そのために PDF をアップロードすることはありません。

ユーザー向けのログインはありません。アプリには社内テスト用の Google ログインを備えた非表示の開発者パネルがあります。そこでログインしても、当社や Google の分析には何も送信されません。当社が指定したテスト用アカウントでログインした場合に限り、そのメールアドレスの一方向ハッシュがその端末の分析データとクラッシュレポートに付加されます。

収集される情報と収集する事業者

これはメモとは別の話であり、当社は2つの説明を意図的に分けて記載しています。以下のいずれにもメモの内容は含まれません。Klave は Google AdMob で広告を表示し、Google Firebase を利用状況の分析（Firebase Analytics）、クラッシュレポート（Firebase Crashlytics）、リモートでの機能設定（Firebase Remote Config）に使用しています。これらが収集する情報は次のとおりです。

次の情報は収集しておらず、当社を通じて端末の外に出ることはありません：メモの本文、ファイル名・フォルダ名、写真や動画、ファイルや文書（PDF を含む）、音声、連絡先、カレンダー、健康とフィットネスのデータ、個人情報、正確な位置情報。Google は広告配信と分析レポートのために IP アドレスから市区町村レベルのおおよその地域を推定することがあり、Google Play のデータセーフティ欄ではこれを「おおよその位置情報」として申告しています。Klave は位置情報の権限を求めず、端末の位置情報を読み取ることはありません。

Klave Lifetime を購入された場合、またはリワード広告を見て有効にしたプラスパスが有効な間は、広告は表示されません。ただし、同意設定と広告非表示の状態を確認するため、広告 SDK が端末上で起動することがあります。分析とクラッシュレポートはすべてのプランで同じように動作します。

メモが保管される場所と、暗号化されるかどうか

暗号化に関する記述は、特定の条件のもとでのみ正しいものです。Klave がメモを読み取り、保管し、送信する場所をすべて記します。

場所暗号化
ご自身で選んだフォルダのメモKlave は暗号化しません。 そのフォルダがどこにあっても、普通のファイルのままです。Klave はその場で読み書きし、そのフォルダにアクセスできる他のアプリや人も読むことができます。
Dropbox のメモKlave は暗号化しません。 Klave は Dropbox のファイルを暗号化された接続（HTTPS）でそのまま読み書きし、Dropbox がお客様のアカウントに保存します。速く開けるよう、開いたことのある Dropbox のファイルの一時コピーをこの端末のキャッシュに置きます。
この端末上の Klave 自身のデータ：設定、ボールトの一覧、最近使ったファイルとスター付きファイル、PDF のメモ・ハイライト・ブックマーク、全文検索インデックス（メモの本文が含まれます）、編集した文書の元の版と以前の版いいえ。 Android が他のアプリから隔離するアプリ専用の保存領域に保管され、Klave をアンインストールすると削除されます。
Dropbox のアクセストークン端末が対応していれば暗号化されます。 Android Keystore で保護された暗号化ストレージに保管し、そのストレージを用意できない端末では、その追加の暗号化なしでアプリ専用の保存領域に保管します。
共有、ダウンロード、他のアプリで開くいいえ。 メモやファイルは、選んだアプリや場所にそのまま渡され、そのアプリのポリシーに従います。
Android OS の端末バックアップ（自動バックアップ・端末間の移行）Klave は暗号化しません。 Android のバックアップがオンの場合、Klave の設定、ボールトの一覧、最近使ったファイルとスター付きファイル、PDF のメモ・ハイライト・ブックマークが Google アカウントのバックアップに含まれ、そのバックアップは Google が管理します。Klave は Dropbox のトークンとログイン情報、検索インデックス、文書の編集履歴、購入状態の情報を除外します。メモのファイル自体は Klave のバックアップには含まれず、フォルダや Dropbox にそのまま残ります。

Dropbox

Dropbox との連携は任意で、どのプランでも無料です。認証は Dropbox 上で行われ、Klave は Dropbox と直接通信します。Velocity Craft がメモを受け取るサーバーを運営することはありません。Klave はフォルダを選べるように Dropbox のフォルダ一覧を表示し、ボールトとして追加したフォルダのファイルを読み書きします。

Dropbox はファイルをお客様のアカウントに保存し、ファイルのパス、サイズ、リビジョン、リクエスト日時、ネットワークアドレスなどのサービス上のメタデータを把握できます。Dropbox による取り扱いは Dropbox のプライバシーポリシーに従います。

Klave の設定で Dropbox との連携を解除すると、この端末からトークンが削除されます。連携を解除しても、Klave をアンインストールしても、Dropbox にあるファイルは削除されません。Klave のアクセスを完全に止めるには、Dropbox のアカウント設定の「連携アプリ」でも Klave の連携を解除してください。

他のサービスに接続する機能

  • 音声入力は、端末の音声認識サービス（ほとんどの端末では Google のもの）を使います。お話しになっている間、音声はそのサービスによって処理され、そのサービス自身のサーバーで、そのサービスのプライバシーポリシーのもとで処理されることがあります。Klave は音声を録音・保存せず、認識されたテキストだけを受け取ります。読み上げには端末の音声合成（TTS）エンジンを使います。
  • メモ内のウェブ画像。 プレビューで開いたメモや HTML ファイルがウェブ上の画像やその他のリソースを参照している場合、プレビューはそのサーバーから読み込みます。ブラウザで開いた場合と同様に、そのサーバーはアドレスとネットワークアドレスを受け取ります。メモのそれ以外の内容は送信されません。ウェブリンクをタップするとブラウザで開きます。
  • フォント。 Klave の画面で使う一部のフォントと、設定で閲覧・選択したフォントは、端末の Google Play 開発者サービスを通じて Google Fonts からダウンロードされます。
  • 文字認識は、スキャンした PDF ページに対して Google ML Kit により端末上で実行されます。Google の ML Kit 利用規約に記載のとおり、このライブラリは技術的な利用状況・性能の指標を Google に送信することがありますが、PDF やその文字は送信しません。
  • アプリの更新は Google Play のアプリ内アップデートでご案内します。

第三者

  • Google AdMob と Google User Messaging Platform — 広告と同意の管理。Google のプライバシーポリシーが適用されます。
  • Google Firebase — Analytics の利用イベント、Crashlytics のクラッシュレポート、機能設定用の Remote Config。メモの内容が Firebase に渡されることはありません。Google のプライバシーポリシーが適用されます。
  • Google Play — Lifetime 購入の決済（当社がお支払い情報を見ることはありません）とアプリ内アップデート。
  • Google ML Kit と Google Fonts — 端末内の文字認識と、ダウンロードされるフォント。
  • Dropbox — アカウントを連携した場合のみ。
  • 端末の音声認識・音声合成のサービス — 使用している間のみ。
  • メモが参照する画像を配信するウェブサーバー — そのようなメモをプレビューで開いたときのみ。

権限

  • インターネットとネットワークの状態 — 広告、分析、Dropbox、音声認識のため。
  • マイク — 音声入力を使っている間のみ、許可された後にのみ使います。Klave は音声をファイルに録音しません。
  • 広告 ID — 広告配信と表示回数の制限のために Google Mobile Ads SDK が追加します。Android の設定 → プライバシー → 広告 でリセットまたは削除できます。
  • ご自身で選んだフォルダ — Klave は Android のフォルダ選択画面を使うため、選んだフォルダしか開けません。すべてのファイルやメディアライブラリ全体へのアクセス権限は求めません。

Klave はカメラ、位置情報、連絡先へのアクセス権限を求めず、通知も送信しません。

欧州経済領域および英国

必要な場合、Klave は広告を表示する前に Google 認定の同意フォームを表示します。選択に応じて、広告はパーソナライズされない形で表示されるか、まったく読み込まれません。このフォームが対象とするのは広告のみです。Firebase Analytics と Crashlytics はこのフォームの対象外で、すべての端末で動作します。Analytics は広告 ID を読み取ることがあり、広告 ID は Android の設定でリセットまたは削除できます。

同意フォームを完了できなかった場合など、広告をリクエストできない間は、設定にフォームを再び開くプラスパスのカードが表示されます。すでに行った選択を変更するための専用の設定項目は、現在の Klave にはありません。その項目ができるまでは、Android の設定で Klave のストレージを消去すると選択がリセットされ、次に Klave を起動したときにフォームが再び表示されます。ストレージを消去すると、Klave がこの端末に保管しているもの（設定、ボールトの一覧、Dropbox との連携、PDF のメモ・ハイライト・ブックマーク）もすべて削除されますが、メモのファイルは削除されません。

お客様には、ご自身のデータへのアクセス、訂正、削除を求める権利があります。メモはご自身が管理するストレージにのみ保存されているため、これらの権利はご自身で直接行使していただけます。ファイルを編集・削除する、Klave をアンインストールしてこの端末に保管された Klave のデータを削除する、Dropbox と Android の端末バックアップをそれぞれの設定で管理する、といった方法です。分析・クラッシュ・広告のデータは Google が保持しており、お名前やメールアドレスとは紐付いていません（上記の当社指定のテスト用アカウントを除く）。これらのデータについては、Google のツールをご利用いただくか、当社にお問い合わせいただければ可能な範囲でお手伝いします。Klave のデータを削除する方法もご覧ください。
