Flori 개인정보처리방침

시행일: 2026-05-10

Flori(이하 "앱")는 사용자의 개인정보를 소중히 여기며, 「개인정보 보호법」에 따라 아래와 같이 개인정보처리방침을 수립하여 공개합니다.

1. 수집하는 정보 항목

도서 라이브러리, 글귀, 사진, 메모는 기본적으로 사용자의 기기에 저장됩니다. 앱은 다음 정보를 수집할 수 있습니다.

  • 도서 메타데이터 검색어: 검색하는 ISBN, 제목, 저자명은 표지 이미지와 서지 정보를 가져오기 위해 공개 도서 메타데이터 제공자(Google Books, 카카오 도서)에 전송됩니다. 이 검색은 사용자 신원과 연결되지 않습니다.
  • 사진 및 이미지: 글귀에 첨부하기 위해 촬영하거나 선택한 사진은 기기에서 처리되고 로컬에 저장됩니다.
  • 계정 정보 (선택): 클라우드 동기화를 위해 로그인하면 Google 계정 ID를 사용하여 AWS Cognito를 통해 동기화 신원이 생성됩니다. 라이브러리, 글귀, 도서 항목이 전송 중 암호화되어 클라우드 데이터베이스에 저장되며 사용자의 여러 기기 간에 미러링됩니다.
  • 구독 상태: 유료 기능을 위해 Google Play Billing에서 구독 상태를 읽어옵니다.
  • 크래시 및 사용 진단 정보: 안정성 향상과 기능 결정을 위해 익명화된 크래시 보고서(Firebase Crashlytics)와 제품 분석 이벤트(Firebase Analytics)를 수집합니다.
  • 위치 정보 (선택): 글귀나 메모에 위치 템플릿 변수를 삽입할 때, 앱은 마지막으로 알려진 위치를 읽어 값으로 채웁니다. 위치 데이터는 삽입된 텍스트 외에는 별도로 저장되지 않습니다.

2. 정보의 수집 및 이용 목적

  • 도서 메타데이터: 도서를 라이브러리에 추가할 때 도서 정보를 미리 채우기 위함
  • 클라우드 동기화: 활성 동기화 구독자의 라이브러리를 여러 기기 간에 동기화
  • 구독: 유료 기능 잠금 해제
  • 진단: 크래시 탐지 및 서비스 품질 향상
  • 위치 템플릿: 사용자가 명시적으로 위치 템플릿 변수를 사용할 때만 현재 위치 삽입

3. 정보의 보유 및 이용 기간

  • 기기 내 데이터: 앱 삭제 시 함께 삭제됩니다.
  • 클라우드 동기화 데이터: 계정이 활성 상태인 동안 보관됩니다. 아래 연락처 이메일을 통해 언제든지 삭제를 요청할 수 있습니다.
  • 진단 정보: Google Firebase의 데이터 보존 정책을 따릅니다.

4. 제3자 제공

앱은 사용자의 개인정보를 판매하지 않습니다. 다음 제3자가 서비스 제공을 위해 제한된 데이터를 처리합니다.

  • Google (Firebase Crashlytics, Analytics, Remote Config; Google Play Billing; Google Books API): Google의 개인정보처리방침을 따릅니다.
  • Amazon Web Services (Cognito, DynamoDB, Lambda): 사용자가 동의한 경우에만 라이브러리 클라우드 동기화에 사용됩니다. AWS의 개인정보처리방침을 따릅니다.
  • 카카오 (카카오 도서 API): 한국어 도서 메타데이터 조회에 사용됩니다. 카카오의 개인정보처리방침을 따릅니다.
  • Dropbox (선택): 백업용 Dropbox 폴더를 연결하면 Dropbox 계정 ID와 OAuth 토큰이 기기에 저장됩니다. Dropbox의 개인정보처리방침을 따릅니다.

5. 앱 접근 권한

  • 인터넷 (INTERNET): 도서 메타데이터, 클라우드 동기화, 결제, 진단에 필수
  • 네트워크 상태 (ACCESS_NETWORK_STATE): 동기화를 위한 연결 상태 확인
  • 마이크 (RECORD_AUDIO): 음성-텍스트 글귀 입력 [선택]
  • 알림 (POST_NOTIFICATIONS): 회상 알림 및 일일 글귀 [선택]
  • 포그라운드 서비스 (FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC): 백그라운드 동기화 [클라우드 동기화 사용 시 필수]
  • 부팅 시 실행 (RECEIVE_BOOT_COMPLETED): 알림 재등록
  • 정확한 알람 (SCHEDULE_EXACT_ALARM): 정확한 시간의 회상 알림 [선택]
  • 웨이크 락 (WAKE_LOCK): 백그라운드 동기화 중단 방지
  • 대략적/정확한 위치 (ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION): 위치 템플릿 변수 사용 시에만 사용 [선택]

선택 권한은 해당 기능 사용 시에만 요청됩니다.

6. 안전성 확보 조치

  • 모든 네트워크 통신은 암호화된 연결(HTTPS)을 사용합니다.
  • 인증 토큰은 Android의 암호화된 SharedPreferences에 저장됩니다.
  • 클라우드 데이터는 TLS로 전송되며 관리되는 AWS 인프라에 저장됩니다.
